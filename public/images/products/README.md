# Product photos go here

Each product in `src/data/products.js` has an `image` field pointing to a file
in this folder, e.g. `/images/products/keychain-sleepy-neko.jpg`.

Just drop in a real photo with the matching filename (jpg, png, or webp — update
the extension in products.js to match) and it will replace the illustrated
placeholder automatically. No code changes needed.

Recommended: square or 4:5 photos, at least 800px on the short side, consistent
lighting/background so the catalog feels cohesive (see DESIGN.md for the
"soft, warm, pastel" art direction this business uses).
